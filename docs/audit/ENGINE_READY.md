# ENGINE_READY (SPEC §32 engine / validator side — live)

`alt` / `resultAlt` (resolved on arrival, stored in `state.altSel`, saved as `rec.altSel`, shown by the UI incl. the ending screen), event `where` + `excludeFactions` (`eligibleEvents(chapter, node)`), save fallback (unknown node id → start of the saved chapter + notice), validator shape checks for `alt` / `resultAlt` / `where` / `excludeFactions` / `bridge:true` / `jump:{zh,en}` (flags must exist, "can never match" warnings from a data-flow), and the story gates are all live. Per route run `node tools/dev/validate.js --faction <id> --allow-missing-ending-art` (the art flag only silences the ending-picture errors; 0 other errors required; story metrics print as a `story (§32)` line and as `story <id>:` WARNs), `node tools/dev/validate.js --faction <id> --story-gate --allow-missing-ending-art` (turns the §32.1 error limits into errors: false choices > 10 %, forced chapter steps > 0, median run > 80), `node tools/dev/validate.js --story-report [--faction <id>]` (compact per-route table + the offending node lists, ~10 s), `node tools/dev/route_converge.js --faction <id>` and `node tools/dev/route_graph.js --faction <id>` (now reads `alt` / `resultAlt`: MUST / MAY status of every flag an alt entry tests). Definitions (tools/dev/story_lib.js): a *false choice* = ≥2 choices, all to the same node, and no choice sets a flag that anything reads (alt / resultAlt / require / grudge / event where / rumour / achievement); a *forced chapter step* = a node whose choices all lead to ONE non-`bridge` node of a later chapter; a *hard jump* = edge with scene change and (≥3 days / years / warp or chapter advance), justified when the target is `bridge:true` or has `jump`, or the source has `jump`. Engine notes for writers: `alt` sees the arrival state (before the node's own effects), the first matching `text` entry replaces the text, at most 2 matching `add` paragraphs follow; `from*` conditions use the previously played node; `resultAlt` replaces `result` (a roll's own `rollResult` still wins) and sees the state before the choice's effects. Event `where` is matched against the node about to be entered; `chapter` takes `{min,max}`; `stat`/`taint` use sibling `min`/`max` like `require`.
