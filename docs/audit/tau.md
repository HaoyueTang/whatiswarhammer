## (a) 路线概要（每章该做什么）

1. **第1章 新邻居**（tau_101–108 + 三个出身序章）：大裂隙后被帝国遗忘六年的新卡尔德投了钛帝国（达尔诺尔）。让玩家看到“好处（工钱、净水）+ 代价（第三批、无人机、‘友好的对话’）”，认识瓦尚、雷娜姨、乔里、以太族奥林，最后和乔里一起报名古维萨。
2. **第2章 火之道**（201–209）：火族教官凯尔拉训练；无人机92号；克鲁特格拉克萨；考尤伏击；领钛语名；运兵船上的前星界军老兵哈斯克。任务：教会钛族战争方式与种姓/盟族。
3. **第3章 绿皮**（301–311）：兽人小行星落地，防线战或克鲁特伏击，军阀与战斗服“蒙卡”；乔里失去手臂；阵亡名单上只有人类和克鲁特。任务：兽人 + 古维萨的位置。
4. **第4章 旧主人**（401–411）：一年后帝国远征舰队来“解放”；雷娜姨点灯/劝阻/告密；与同胞交火；星际战士；影日的考尤反包围；帝国战俘；瓦尚邀你做联络官。任务：帝国作为敌人、影日。
5. **第5章 远见**（501–510）：凯尔拉对远见的向往；奥林第二次讲话；亚空间浅潜的噩梦；西拉斯的混沌小团体；红色战斗服的叛逃邀请；瓦尚的晚饭。任务：远见分裂、以太族的“平静”、混沌对人类的诱惑。
6. **第6章 阴影**（601–611）：人类做同一个噩梦，生物质逼近；撤离按种姓排批；克鲁特不在名单；雷娜姨不走；难民营里的基因窃取者；港口关门，第三批“暂时推迟”。任务：虫族的影子、大义的排序。
7. **第7章 吞噬**（701–708）：虫潮、突触节点、格拉克萨战死或92号被毁、奥林被巢穴暴君杀死、火族僵住而人类没有；影日舰队五天后到；人类集体流鼻血（亚空间阴影）。
8. **第8章 虫群主宰**（801–807 + 结局）：虫群主宰学习战术；掩护凯尔拉/带平民上船/握吊坠/献祭；舰队抵达；在 807 选结局：远见飞地、大义公民、守望者、回去找92号。
9. 结局 14 个：3 good（citizen / watch / enclaves）、4 普通 bad（reeducation / collaborator / gate / devoured）、4 claim、3 death。
10. 当前骨架是**一条线性主干 + 每节点两三句不同的结果句**：36 个“假选择”节点、约 25 个旗标设了从不读、7 次章节强制跳转、34 处无过渡硬跳；结局几乎全部在最后一个节点按菜单挑选——这就是“跳得很厉害、选项没有后续”的根源。
